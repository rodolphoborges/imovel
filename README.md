# Atlas Imobiliário

Projeto demonstrativo de catalogação, pesquisa e comparação de anúncios imobiliários em São Paulo.

## Escopo
- Filtros por preço, área e rua
- Comparação de características e custos anunciados
- Favoritos armazenados localmente no navegador
- Mapa ilustrativo da área de cobertura

Os registros são preliminares e não representam ofertas verificadas. A seleção geográfica é um recorte de pesquisa e não indica residência, propriedade ou intenção de compra de qualquer colaborador.

Site estático compatível com GitHub Pages.
